About GoIntern

구성원은 AI로 일하고, 관리자는 업무 환경을 구성합니다

GoIntern은 구성원이 일상 업무에 AI를 활용하는 사용자 서비스와 조직의 AI Agent, 사용자, 콘텐츠와 연동 환경을 관리하는 관리자 서비스로 구성됩니다. AI를 사용하는 화면과 이를 조직에 맞게 운영하는 관리 환경을 함께 제공해 기업이 AI를 실제 업무에 적용할 수 있도록 합니다.

AI Tools

업무에 필요한 AI 기능을 바로 사용합니다.

문서와 데이터를 분석하고 이미지를 생성하는 등 업무에 필요한 AI 기능을 별도의 프로그램 없이 사용할 수 있습니다.

  • 데이터 분석

    업로드한 데이터를 확인하고 필요한 내용을 분석

  • 이미지 생성

    업무에 필요한 이미지와 시각 자료 생성

  • 문서 분석

    문서의 내용을 읽고 필요한 정보 확인

AI Chat

업무 내용을 AI와 대화하며 처리합니다.

아이디어를 정리하고 문서와 보고서를 작성하거나, 필요한 정보를 질문하고 분석할 수 있습니다.

  • 아이디어 정리

    브레인스토밍과 초안 작성

  • 문서 작성

    보고서·기획안·업무 문서 작성

  • 데이터 분석

    데이터를 바탕으로 질문하고 결과 확인

AI Interns

업무에 맞는 AI 인턴을 선택합니다.

업무 목적에 따라 필요한 역할의 AI 인턴을 선택해 사용할 수 있습니다. 각 인턴은 역할에 맞는 지식과 Prompt, 필요한 업무 기능을 기반으로 구성됩니다.

User Management

사용자와 접근 권한을 관리합니다.

구성원별로 사용할 수 있는 서비스와 콘텐츠, AI 기능의 접근 범위를 설정할 수 있습니다.

  • 사용자 관리

    계정 등록과 상태 관리

  • 권한 관리

    사용자별 기능 접근 설정

  • 콘텐츠 권한

Content Management

회사의 문서와 데이터를 AI에 연결합니다.

업무에 필요한 문서를 등록하고 외부 저장소의 콘텐츠를 연결해 AI 인턴과 검색 기능에서 활용할 수 있습니다.

  • 파일 업로드

  • Google Drive

  • SharePoint

  • 문서 권한 설정

App Management

조직에서 사용하는 업무 서비스를 연결합니다.

메일, 일정, 협업 도구와 파일 서비스를 연결하고 조직에서 사용할 기능을 관리합니다.

Usage Analytics

AI 사용 현황을 확인합니다.
