Financial RAG

금융 문서에서 필요한 정보를 근거와 함께 찾습니다.

상품 설명서와 내부 규정, 뉴스 등 금융 문서에서 질문과 관련된 내용을 찾고 답변에 활용합니다. 필요한 경우 검색어를 보정하고 결과를 다시 정리해 관련성이 높은 정보를 찾습니다.

  1. 01 Document Processing

    문서 처리

    PDF · HWP · Word · 웹페이지 등 다양한 금융 문서 처리

  2. 02 OCR

    문서 인식

    스캔 문서와 이미지 기반 자료에서 텍스트 추출

  3. 03 Reranking

    검색 결과 정리

    질문과 관련성이 높은 내용을 우선적으로 확인

  4. 04 Query Refinement

    검색어 보정

    검색 결과가 부족하면 질문에 맞게 검색 조건을 조정

  5. 05 References

    근거 확인

    답변에 활용한 문서와 참고 정보 확인

AI Agent

질문을 이해하고, 필요한 금융 업무까지 실행합니다.

금융 정보를 찾아 답하는 데서 끝나지 않고, 요청에 맞는 API와 기능을 선택해 조회·분석·추천 등 필요한 업무로 이어갑니다. 주식, 연금, 보험 등 업무 영역에 따라 필요한 기능을 다르게 구성할 수 있습니다.

  1. 01 Understand

    요청 이해

    어떤 금융 업무가 필요한지 파악

  2. 02 Select

    기능 선택

    요청에 필요한 금융 API와 기능 선택

  3. 03 Execute

    업무 실행

    조회·분석·추천·거래 요청 등 연결된 기능 실행

  4. 04 Respond

    결과 안내

    처리 결과와 필요한 정보 전달

Private AI

금융사 내부 환경에서도 AI를 운영할 수 있습니다.

외부 AI API 사용이 제한되는 환경에서는 오픈소스 모델을 내부 GPU 환경에 배포해 운영할 수 있습니다. 고객사별 데이터와 모델 환경을 분리하고 사용자별 접근 범위를 적용할 수 있습니다.

  • On-Premise

    내부 AI 운영
