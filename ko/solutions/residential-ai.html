Voice AI

주거 환경에 맞춘 실시간 음성 처리

음성 인식부터 요청 처리, 기능 실행, 음성 안내까지 하나의 흐름으로 구성합니다. 여러 단계의 입력과 생활 소음까지 실제 사용 환경을 고려해 처리합니다.

  • 실시간 음성 인식

    Whisper와 Qwen 계열 모델을 활용해 사용자의 음성을 실시간으로 인식하고 스트리밍 방식으로 처리합니다.

  • 이어지는 요청 처리

    방문자 등록처럼 여러 단계가 필요한 요청은 앞선 내용을 이어받아 필요한 정보를 순서대로 확인합니다. 응답 중 새로운 발화가 들어오면 기존 응답을 멈추고 다음 요청을 처리할 수 있습니다.

  • 실시간 음성 안내

    Qwen 계열 TTS를 활용해 처리 결과를 음성으로 전달하며, 서비스에 적용할 수 있는 한국어 커스텀 음성 5종을 구현했습니다.

  • 생활 환경을 고려한 음성 처리

    Silero VAD와 DeepFilterNet3를 활용해 발화 구간을 구분하고 주변 생활 소음을 줄여 안정적인 음성 인식을 지원합니다.

Autonomous Experience

Security

세대별 데이터와 접근 권한을 분리합니다.

주거 서비스에는 대화 기록과 방문 정보처럼 민감한 데이터가 포함될 수 있습니다. 세대별 데이터 분리와 암호화, API 인증, 관리자 권한 관리를 적용해 서비스 운영에 필요한 보안 구조를 구성합니다.

  • Secure API
