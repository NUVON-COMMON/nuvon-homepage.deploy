    Voice AI

    Real-Time Voice Processing for Residential Environments

    From speech recognition to request handling, function execution, and voice responses, the entire process works as one continuous flow. It handles multi-step requests and everyday background noise with real-world living environments in mind.

    • Real-Time Speech Recognition

      Whisper and Qwen models recognize user speech in real time and process it through streaming.

    • Multi-Step Request Handling

      For tasks like visitor registration, the system carries context forward and collects the required information step by step. If a user speaks while a response is playing, the system can stop the current response and handle the next request.

    • Real-Time Voice Responses

      Qwen-based TTS delivers spoken responses. Five custom Korean voices have been developed for service integration.

    • Voice Processing for Everyday Environments

      Silero VAD and DeepFilterNet3 detect speech segments and reduce background noise to support reliable speech recognition.
