    Privacy & Security

    Standards for Handling Sensitive Customer Data

    Clinic marketing systems hold personal information such as names, contact details, and consultation history. NUVON LABS builds in the protections needed at the data storage and user access layers.

    Direct handling of medical information or clinical records has not been confirmed, so this is not presented as a medical data platform.

    • Data Encryption

      AES-256 encryption for customer names and phone numbers

    • Duplicate Detection

      Duplicate customer detection using phone number hashes

    • Password Security

      PBKDF2-based password protection

    • Role-Based Access

      Feature and data access control by user role

    • Consent History

      Records of consent to personal data collection

    • Log Masking

      Masking of personal data in operational logs

    • Secure Consultation Link

      One-time token-based consultation links
